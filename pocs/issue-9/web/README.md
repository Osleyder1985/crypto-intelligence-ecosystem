# Issue 9 web chart reference PoC

This is a dependency-free browser reference implementation for checking the shared synthetic OHLCV fixture and chart geometry. It is **not** a React/Vite candidate and must not be scored as if it were one. It provides a low-dependency visual baseline only.

## Run locally

Requirements: Python 3 for the static file server and Node.js 22 for geometry tests and benchmark. From the repository root:

```bash
cd pocs/issue-9/web
npm test
npm run benchmark
cd ../../..
python -m http.server 8000
```

Open `http://localhost:8000/pocs/issue-9/web/`. The app loads `/tests/stack_poc/fixtures/ohlcv_synthetic_v1.json`, draws candlesticks and volume, and shows a text table. It does not connect to an exchange, submit orders, or generate investment advice.

## Automated checks

The GitHub Actions workflow runs Node.js tests for geometry bounds, rising/falling candles, flat-price input and invalid dimensions. It verifies the fixture provenance marker and runs the geometry microbenchmark in three fresh Node processes. Each process performs 100 warm-up iterations and 1,000 measured iterations. Raw JSON outputs and an aggregate summary (median of process medians and range) are uploaded as a CI artifact. The reports include Node version, OS, CPU model, logical CPU count, installed RAM, fixture SHA-256, duration distribution, and RSS observations before/after.

## Benchmark interpretation

The benchmark measures **JavaScript geometry calculation only**. It does not measure browser rendering, layout, GPU work, memory peak, app cold start, or end-to-end chart readiness. RSS is sampled at two points and must not be called peak memory. CI output is specific to its hosted runner; it must not be compared directly to local Windows, Android, iOS or another runner.

For a local result, save the full JSON output together with the exact commit SHA, Windows build, CPU/RAM, Node version, browser version, power mode, and timestamp. Repeat on the same machine at least three times before reporting a local median/range. Keep CI and local result tables separate.
